# Agents Collab v0.1.1

This experimental release packages the Codex-led Agents Collab skill
and its optional macOS arm64 record backend. It includes the reviewed changes
from [PR #4](https://github.com/jaredchu/agents-collab/pull/4).

## Changes

- Check that CLI record and host directories stay in private storage outside
  the project. Recheck registered output paths before rendering a dispatch or
  recording a quota replacement.
- Add a read-only Claude CLI review renderer. It prepares the sealed review
  instructions and output contract. The host still launches Claude Code and
  retains its terminal result.
- Clarify cross-host handoff, unfinished work after quota limits, and recovery
  after a partial helper failure.
- Retain the explicit `route --review-required` workflow and format 6 records.
  The CLI continues to read formats 1–4 and 6.

## Packages

- `agents-collab-skill.zip` contains the skill, helpers and MIT license.
- `agents-collab-0.1.1-darwin-arm64.tar.gz` contains the optional CLI, manifest
  and MIT license. It targets macOS arm64 with local APFS record storage.
- `SHA256SUMS` covers both archives. Verify them in the download directory
  with `shasum -a 256 -c SHA256SUMS`.

See the [skill installation guide](../guide.md) and the
[CLI installation instructions](../cli.md#optional-backend-installation).

## Scope

A fresh isolated install completed one explicit opt-in task with a passing
independent review of the frozen final artifact and a verified format 6 record.
Dependable implicit activation remains unverified. Codex leads the workflow,
with Claude CLI available as a review transport. The backend records structural evidence and does not dispatch models
or attest runtime identity, effort or liveness.
