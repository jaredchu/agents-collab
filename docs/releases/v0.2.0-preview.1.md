# Agents Collab v0.2.0-preview.1

This experimental prerelease adds opt-in effort selection for delegated writers
and reviewers in Codex-led workflows.

## Profile migration

**For delegates, `inherit` now copies the active lead's captured effort.** If an
existing delegate uses `"reasoning": "inherit"` to keep its own interface setting,
change that delegate to `"reasoning": "interface-default"`. Keep
`"reasoning": "inherit"` for the host lead. Fixed effort levels continue to work
as before. The profile wizard defaults delegates to `interface-default`.

When a delegate is configured to inherit the lead's effort, the lead must know
its current level and verify that the delegate's interface accepts it. The
optional CLI helper takes that level via `assignment --lead-effort LEVEL` and
records it for retries of the same assignment. See the
[profile reasoning rules](https://github.com/jaredchu/agents-collab/blob/v0.2.0-preview.1/skills/agents-collab/references/configuration.md#lead-effort-inheritance).

## Changes

- Set `"reasoning": "auto"` on a delegate to opt in. It selects Medium when the
  declared scope names one exact file and the sealed source contains only that
  same regular file. Broader and ambiguous assignments use High.
- Keep the requested policy separate from the concrete effort in dispatch and
  observation records. The helper checks running and completed receipts against
  the resolved effort.
- Keep the optional Rust backend at v0.1.1. This prerelease updates the skill and
  its Python helpers. It uses the existing backend and record formats.

## Downloads

- `agents-collab-skill.zip` contains the skill, helpers, and MIT license.
- `agents-collab-0.1.1-darwin-arm64.tar.gz` is the existing optional backend
  for macOS arm64 with local APFS record storage.
- `SHA256SUMS` covers both archives. Run `shasum -a 256 -c SHA256SUMS` in the
  download directory to verify them.

## Evidence and limits

In matched synthetic Opus trials, both effort arms found all 11 seeded review
defects. Both writer arms passed all 24 acceptance checks on the first attempt
with zero follow-up repairs. The Medium/High arm used 9.4% less summed writer
time on the four bounded cases. These are small single-model trials. Production
quality, runtime reasoning, and dependable implicit skill activation remain
unverified. [Review trial](https://github.com/jaredchu/agents-collab/blob/v0.2.0-preview.1/docs/experiments.md#6-harder-matched-review-effort-trial) ·
[Writer trial](https://github.com/jaredchu/agents-collab/blob/v0.2.0-preview.1/docs/experiments.md#7-matched-opus-writer-effort-trial)
